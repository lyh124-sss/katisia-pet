# 🌸 Katisia Pet (卡提希娅桌面宠物)

一个基于 Electron 从零开始开发的极简二次元桌宠。支持状态切换、语音互动、拖拽移动与右键退出。

## ✨ 功能特性
- 🎭 **多状态无缝切换**：待机、脸红、睡觉、走动等状态自动切换（基于 GIF）。
- 💬 **语音与气泡互动**：点击桌宠即可触发随机台词，同步播放本地语音，并弹出漫画风气泡。
- 🤸 **Q弹的动画反馈**：点击时有缩放回弹效果，被拖拽时带有物理悬空/摇晃感。
- 🖱️ **沉浸式交互**：无边框透明窗口，无任务栏图标，鼠标右键即可退出程序。

 ## 🛠️ 技术栈
- **核心框架**：Electron (v37.x)
- **前端基础**：原生 HTML5 / CSS3 / JavaScript (ES6+)
- **音频处理**：Web Audio API (实现语音播报与可能的声波驱动)
- **动画与状态机**：CSS Keyframes 动画 / JS 状态机 / GIF 切换
- **打包工具**：electron-builder
- **开发辅助**：DeepSeek Harness (AI 辅助生成代码骨架与逻辑)
